流媒体相关

从媒体库/历史打开媒体时用新的浏览器标签页：下面的规则（JSON 数组）命中任意一条才开新页，一条规则里写了的字段要同时匹配。{"profile":"gal-import"} = 这个导入方案的媒体；{"kind":"text"} = 这种类型；{"profile":"rj-media","kind":"video"} = 该方案里的该类型。空 = 都在当前页。用下拉选好点「添加规则」会加一条，要删就直接改 JSON。Ctrl/⌘ 点击任何媒体都会用新标签页。
点媒体库卡片时直接进浏览（不进目录）：下面的规则（JSON 数组）命中任意一条、且这个条目的单元数 ≥ 1 且 < unitsBelow 就直接去浏览（接着上次看到的单元，没看过就是第一个）。{"profile":"gal-import","unitsBelow":2} = 这个导入方案、只有 1 个单元时直接进；{"kind":"video","unitsBelow":4} = 视频类、单元数 1–3 个时直接进；profile / kind 都不写 = 任何条目。空 = 一律进目录。卡片上的「目录」按钮永远进目录。
点标签（搜索）时用新的浏览器标签页：规则格式和上面一样，按标签所在条目的导入方案/类型判断，和「打开媒体」分开；Ctrl/⌘ 点击任何标签都会用新标签页，「标签管理」页的标签只响应 Ctrl/⌘ 点击。新标签页不保存搜索状态。

朗读（TTS）

规则作用在发给 TTS 的文本上，显示的文字不变；缓存按替换后的文本存，改规则只会重新生成受影响的句子。没有任何字母/汉字/假名的句子（＊＊＊、省略号、纯数字）会自动跳过，不用写规则。

              
              
每条规则：match（选择器；@kana = 所在段落有假名；* = 兜底，只在这一章至少有一条别的规则命中时才生效）、flag（你起的名字，比如 ja / zh），以及可选的这个 flag 自己的 TTS 参数：speaker_audio、prompt_audio、prompt_text、text_language、prompt_language（名字和 GSV-TTS-Lite 接口一致）。没写的参数用上面的「默认」；参考音频三件套（speaker_audio / prompt_audio / prompt_text）只要写了其中一个就整组用规则里的，两个语言各自单独回落。同一个 flag 写在多条规则里只取第一条的参数；没命中任何规则的句子用默认。选择器支持：标签、.类、#id、[属性]、[属性=值]、[属性*=值]、:not(…)、空格（后代）、>（子元素）、逗号。空 = 不分类，全部用默认。
