# 天結いラビリンスマイスター：执行链与原生绘图函数

状态：仍未注册可播放 AGE 适配器。以下是已执行的原始数据验证，不等同于完整剧情或原版截图对照验收。本轮无需升级媒体镜像；新采集脚本单独同步到 bootstrap 使用的分支。

## 已实现

- 字符串数组的 type14 指针，支持读、写及以已有指针为基址；字符串不会被整数转换成0。整数/字符串指针类型不匹配、未初始化指针及越界均拒绝。
- opcode3 按原始资源 ordinal 调用另一份 BIN，区分函数返回与脚本退出；共享全局变量，跨 BIN 保存/恢复调用方局部变量和指针。缺少子脚本时明确报告 missing-script 和 ordinal；限制脚本数、栈深与总步数。原有默认追踪仍会在未知指令处停止。
- 原生 CSINIT 真实调用：16971 → 底图16970 `CSB005AAA.AGF`、补丁16971 `CSB005AAB.AGF`，偏移 `(600,280)`。这组验证的是映射，未假称收到或显示过这两张图片。
- `createAgeGraphics` 数据模型：整图纹理加载、纹理与对象查询、原始裁剪矩形、绘图位置与内存限制。没有安装运行时，也不执行原始 EXE/DLL。
- 原生 `SYSTEM4` 2040入口的纯初始化函数返回成功；由其取得纹理ID，并执行 SC0000 的155991入口图片放置函数。真实采集 BG054AA 1600×900 落在 `(0,0)`；CS001AAA 1344×928 落在 `(128,-28)`；换成 CS002AAA 1152×864 后落在 `(224,36)`，中心800、底部900保持。不是手写期望坐标替换原生放置函数。

## 仍未确认

绘图查询含义由原生辅助函数的读写关系交叉检查，尚无原版截图的像素对照。追踪器在绘制后的 opcode0x242 仍明确停止，不推测其为显示/隐藏并跳过。完整 SN0000 从入口执行仍在0x1f4停止；图形事务、动画/显示属性、部分声音状态及交互回调还需查实现。尚未串成完整播放器，不发布“可播放”版本。

此前收到的25份依赖长度及SHA都再次核对通过；缺口不是 SN0000 没收到。现有4,841,216字节 AGE.EXE 的代码段为高熵打包数据，入口位于末尾数据段，不能按公开旧版函数地址直接反汇编。

## 精确补采：1.66

已有目录清单还包含 **AGE.EXE.org，4,431,616字节**（以及同体积的 AGE - コピー.EXE）。本轮只收前者，用于检查原版备份是否保留可读代码与指令分发表；“备份”文件名不能保证未加壳，收到后必须验证。

默认规则 `^new-games:age-code$`，仅天結い一个目录、一个完整文件，约4.23 MiB压缩前；SYS4INI.BIN 的已知SHA作为版本守卫，原文件体积必须与已收清单一致。其他游戏、ALF、媒体、存档均不采，源目录只读；EXE仅作为字节数据打包，绝不执行或加入镜像。`GAL_COLLECT_TSK_LOG` 的优先级保持。

用户仍运行原来的 `bash gal-collect.sh .`。若本机设置过 GAL_COLLECT_RULES，可显式使用 `GAL_COLLECT_RULES='^new-games:age-code$' bash gal-collect.sh .`。
