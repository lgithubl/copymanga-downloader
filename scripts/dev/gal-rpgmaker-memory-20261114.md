# RJ01271506 回想入口修复（2026-11-14）

原因：原来的目录只按台词数或 CG 证据收录事件。Map051/052 的 77 个回想菜单页通过 Memory.start、原生开关/变量/队伍/自开关、传送进入正文，菜单自己没有足够台词。传送接续只支持单事件地图，普通地图中的这些正文因而没有被接上。

现在从已启用的 inazuma/Memory 插件识别原生入口，按入口原有的各个选项收录 198 条分支到特殊场景及地图列表；不要求存在 CG 或背景。每个分支保留原始初始化和正文选择。接续仅跟随入口控制状态关联的自动事件，遵循原生事件页的优先级和自开关条件；共用模板跨地图移动后保留进度，不把普通地图上的全部事件串起来。

补充支持 CommonEventExtend 的参数条件、原生进度向上取整表达式，以及 SelfSwitchesEx 的指定地图/事件自开关。传送先记住当时的分支条件，当前事件结束后再开始下张地图的自动事件。原生 Memory.back 结束本轮回想，不执行普通游戏恢复流程。没有原游戏最近观看存档时从头回想；中途续播由现有阅读器进度/标记提供。

配置仅对 `rpgmaker::rj01271506` 开启 `plugins.memoryReplay`，通用默认关闭；gal-layout 版本 2.64.4。须更新镜像和统一 tag 包，然后重新执行本游戏 gal-layout。

## 2.64.4：实际导入链修复与语音核对

用户反馈版本已是 2.64.3，但特殊场景仍只有 20 项。已用真实采集数据复现：大写 `rpgmaker::RJ01271506` 没命中小写内置 profile，退回通用配置，导致 memoryReplay/TRN 自动语音关闭，DLC 和 Skit 配置同时丢失。之前浏览器测试手工注入了专用参数，绕过了真实 layout 路径，因此没有发现这个错误。

现在只对内置已知 RPG Maker profile 的 ID 提供大小写别名，保留用户原 ID、标题和精确覆盖项；其他引擎、未知自定义 ID 不改变匹配方式。实际导入使用大写 ID，执行 generateTags 并保存其输出后，公共 reader 列表可找到“照料花朵”，真实浏览器显示原立绘和下一句，不再手工补 profile。已保存的错误通用配置也覆盖了回归测试。采集数据中修复后为 478 个特殊场景卡片，含 198 条新回想分支。

原目录清单中的 12,882 个非空 unique 语音文件与原 voice_list 逐项一致；对 198 条默认路径上每个实际发出的语音地址均检查对应实体文件在源清单中存在。“照料花朵”有 39 次语音，“森林泉畔的时光”有 73 次。
