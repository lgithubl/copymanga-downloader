### 05_汎用アダルト_ユニーク部分1_2_昼■ 只见下半身

原生 `systemex` 的 setEx 是对同一组三层设置缩放、载入图片、再移动；`system` 还定义了 setc/pivot 和 initRectTransform。现在 center 模式没有实现 setc，不能断言原生 pivot 与默认中心相同。此前未采这两张出错图片，尺寸和透明边界尚未对照。因此已锁定坐标/锚点/原尺寸缩放的验证范围，但“高分辨率本身导致裁切”尚未证实。

### 12_エンディング白3■ 第 48 句图层分离

已用原始脚本和实际状态机复现。第 47 句身体与表情都在 (550,-30)，缩放 1；随后 `fade_set(C2,"N-ShiroFacial-03-scared01.png",0.3)` 换脸。第 48 句身体仍在 (550,-30)，C2 的 x/y/scale 却丢失，回到默认位置。

原因是 center 模式 layerCmd 发新 src 时没有 merge，通用引擎将该槽重置。原生 set/fade_set 只调用 SetImage，并没有重置位置；同一份 `system` 的 set 内默认位置调用甚至被注释掉了。

修复应按该模式保留既有图层几何；首次初始化/删除的行为另外遵循原生定义。需要覆盖连续翻句和直接定位第 48 句，防止只验证其中一种。Remastered 的 canvas 模式 set 与 set2 语义需单独保持。
