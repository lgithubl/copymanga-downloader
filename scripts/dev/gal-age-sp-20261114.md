# 天結 SP0023 缺图、缩略图与私用字符

采集 1.69 的 108 个原始 BIN 复现：SP0023 有 138 段正文，但图片列表为空。严格初始化在 SHINIT2 的 0x135 停止，尚未执行 INIT2 460–640 的独立调用表赋值；后续 EVINIT 调用因此缺失，场景尝试把 0 当作图片编号。先前开场/G0001 的有限验证没有覆盖这条 SP 路径。

修复仅对已核对 SHA-256 的 INIT2 恢复独立的 36 条字面量赋值块，并验证块边界、指令和链接脚本头。原生启动调用列表中完整的字面量常量表也可读取，包含分支/指针/绘图的初始化段不跳过后强行应用。完整启动仍明确记录在 SHINIT2 停止，不能宣称完整原引擎已实现。

SP0023 原路径由 EVINIT 选出 EV130A/EV131A 及 14 张差分。采集 1.70/1.71 的真实素材用于验证，不伪造图片编号或画面。另补全 0x207 不透明纹理矩形拷贝：保留原始裁剪/坐标，更新已引用纹理的绘图对象；透明/复合来源等未实现变体继续报告，不近似成另一种混合方式。差分跟随主图更换与擦除。

首句中的“方框”是 Shift-JIS F040 解码后的 U+E000，而不是整段解码失败。原档案确实含 AGE-EXTEND.TTF，旧原生引擎也通过 AddFontMemResourceEx 注册 AGE Extend。现在从本地 ALF 按需提供原字体，浏览器仅在 U+E000–E004 范围使用它，不猜测替换成其他标点、不安装系统字体、不下载依赖。离开播放器时释放字体。

正常导入后的 SP 卡片可由图片指令生成缩略图。可配置 maxSteps 的默认预算改为 500000，避免启用真实数据调用后 G0001 在原来 100000 步预算处截断；最高仍由纯数据 VM 的 1000000 步保护限制。

验证：gal-age-sp-selftest.mjs 覆盖真实资源编号、普通列表/reader、CG/差分/字体与矩形拷贝边界；fe-gal-age-sp-selftest.mjs 从真实媒体列表进入，连续检查全部 138 段原文、原字体加载、五处 CG/差分画面和上一句恢复。像素比较把两个 Canvas 固定到 CPU，避免 Chrome 因多次读回只把被测 Canvas 切到 CPU 后，GPU/CPU 的插值边缘差异造成假失败。浏览器证据保留在 .cache/age-sp-reader/browser。

未实现指令仍保留逐句诊断，其他 SP 尚未逐场做浏览器对照；这次修复不意味着整个 AGE 引擎的动画、分支和原生系统均已还原。

回归通过：AGE adapter 30 项、普通原生导入、原开场/G0001 浏览器、SP 后端 3 项/浏览器、布局漂移 8 项、导入下拉、旧 KiriKiri 布局及 BGI 58 项。额外尝试的 gal-selftest.mjs 因本机缺少 ImageMagick convert 停止，未为此安装新依赖。
