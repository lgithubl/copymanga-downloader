# RJ01746557 接入与实测（2026-11-15）

游戏：《寝取られVtuberは笑わない》，本次采集的是 Yurei_1-0-0 的汉化构建，Unity 6000.3.11f1 / Naninovel。复用 `naninovel::script` 家族，补齐 Resources 构建支持；已有 Addressables 路径保持兼容。分支 `feat/gal-download`。

## 导入

更新本次镜像后，导入方案左侧仍选通用 **Naninovel 原生 Unity（Resources / Addressables）**，无需新增一个游戏专用适配器。JSON 示例：

```json
{
  "rootDir": "/data/library/gal/RJ01746557",
  "adapters": ["naninovel::script"],
  "defaultMetadataActions": ["gal-layout"],
  "dryRun": false,
  "config": {
    "game": {
      "id": "naninovel::RJ01746557",
      "title": "寝取られVtuberは笑わない"
    }
  }
}
```

rootDir 指向实际游戏目录，支持外层再套一层发行目录。用户设置的 title 优先；`gal-layout` 版本为 2.66.2。已有条目更新镜像后重新运行 layout，并刷新列表。仅替换 tag 脚本不足以获得这次服务端解析支持。

## 资源与场景

- 45 个原始 playlist 全部通过逐字段、严格尾部校验；使用随镜像内置的静态字段描述，没有运行程序集或下载类型数据库。
- ResourceManager 的小写路径和原生 Assets / ProjectResources 表联合还原大小写及资源映射，优先 Sprite 子资源，保留裁切和原始画布。
- 从 15 个原始 RecollectionButton 获取回想的真实脚本和 label，生成 15 张“特殊场景”卡片，不按文件名或 CG 猜测入口。
- 导出共 80 份小脚本：45 原始脚本、15 回想入口、20 个实际跨文件 label 目的地。后两类是读取入口，不是新剧情；不应把 80 当成 80 个独立场景。
- 角色 / 背景 / CG / 音频读取原始 Unity 对象，纹理与音频流按请求范围解码。回想入口和 CG 变化支持现有中途开始标记及渲染缩略图。
- 支持原生选项、局部标签跳转、跨脚本标签目标、条件与变量赋值；回想使用原生 is_replay 语义。不能将选项后的 Stop 当成整个脚本结束。
- 角色按配置的 SceneOrigin 和 Pivot / PPU 摆放。实际发现并修复了头部被裁切的问题；严格限制的小数像素边界修正允许原生 tight Sprite 的单像素栅格 padding，仍拒绝真正越界的元数据。
- 背景与人物 / CG 在缩略图评分中分别处理，避免开场黑底抢占缩略图。未标注类别的旧 overlay 评分不变。
- 本次真实场景的配音以 PlaySfx 人声循环为主，不应称为逐句配音；按原始命令起止，人声与环境循环可以共存。

## 明确边界

本实现是剧情阅读器，不运行 Unity 游戏逻辑。触摸探索自定义 UI 尚未实现；ShowUI 后原生 Stop 会停下并记录 `native-ui-stop`，包含脚本和原始行号，不静默串播 UI 后面的正文。相应剧情可从原生回想入口或独立剧情条目进入。

自定义情绪图标、部分抖动 / 故障特效、拟声文字动画等尚未全部还原，会记录 raw 诊断。不能据此宣称原游戏整段交互完全执行。没有发现本构建包含实际 Live2D 模型、视频 CG 或动画剪辑；动态贴图演出尚未另行证实，不将程序集里存在 Live2D.dll 视为动态 CG 的证据。

## 采集与验证

采集脚本 2.24 → 2.25 → 2.26 分三轮，源目录只读。第一轮目录探测；第二轮只采约 47 MB 资源元数据与剧情程序集；第三轮只采两种真实画面引用的 7 段纹理 / 音频，共 40,167,840 字节。没有整份传输 2.8 GB 纹理流。原始范围逐段 SHA256 核对后，在本地稀疏文件中重建供测试。

- `gal-naninovel-resources-selftest.mjs`：真实导入 → layout → 列表 / 场景 / 15 回想；原图 PNG 与音频 Ogg；中途标记；跨脚本目标；分支和停止边界；严格 Sprite 边界。
- `fe-gal-naninovel-resources-selftest.mjs`：真实浏览器渲染 scene-1 的背景及人物、scene-4 的 CG；前者 BGM 实际播放，后者人声与环境两个循环实际播放；两者合成缩略图均成功。
- `gal-six-unity-selftest.mjs` / `gal-six-native-mz-selftest.mjs`：旧 Naninovel、Utage、Unite、CellTalk、MZ 的原始场景和资源回归。
- `fe-gal-import-presets-selftest.mjs`：通用 Naninovel 下拉及刷新 JSON，不改变用户其他配置，不自动保存。
- `gal-layout-rules-selftest.mjs`：适配器默认参数和布局表漂移守卫。

本地证据位于 `.cache/rj01746557/`：`round1` / `round2` / `round3` 原始采集；`all-decoded.json` 原始脚本解码；`gallery.json` 原始回想映射；`verified/integration.json` 后端验证；`verified/browser/verification.json`、截图及合成缩略图。游戏原始素材不提交仓库。
