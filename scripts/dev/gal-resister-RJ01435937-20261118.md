# RJ01435937 / ReSister

新增独立 `resister::unity`，不扩大旧 Unity / CatPaw / Kaiju 家族的匹配范围。导入方案的“刷新 JSON”下拉已加入 ReSister；layout 版本2.89.0。

```json
{
  "rootDir": "/data/library/gal/RJ01435937",
  "adapters": ["resister::unity"],
  "defaultMetadataActions": ["gal-layout"],
  "dryRun": false,
  "config": {
    "game": { "id": "resister::RJ01435937", "title": "ReSister" }
  }
}
```

`rootDir` 指向包含 `ReSister_Data` 的游戏目录。完整保留原始 StreamingAssets、资源文件与已安装的 DLC；本适配器不下载游戏资源或解码器。语言默认简中，可在 `config.adapterOptions["resister::unity"].language` 选择 `ja`、`en`、`zh-CN`、`zh-TW`。

## 已接入

- 原生 Unity6000.0.61f1 / IL2CPP metadata31，GameHOne 控制器。22个 Live2D 模型，21个互动场景（包括本地 DLC）。MOC、全部纹理页、物理和动作严格按 model3、Addressables 容器及模型身份关联。
- 246个有效条目（含21个互动）；主线/日常/特殊场景/互动分组。特殊场景按原作 ImageMemoryItem / EventImageItem.scenario 关联，不用文件名猜测。
- 原表的4种语言；本轮默认简中解析3229个文本步骤。没有为无配音台词拼接随机语音：剧情表只有5条显式 voice 指令。
- 原作背景别名、BGM、音效别名、语音映射。原生立绘的18种情绪端点、31个已确认的立绘/服装/眼色指令别名；切换参数在同一模型上累积，不丢前一个状态。
- 互动提供原始动作、独立语音分组、模型状态参数；沿用多选、自动/长按、语音结束再触发和各游戏独立设置。动作选择在点击语音时保留。可直接从右侧切换到其余互动场景。
- 动态模型参与原有缩略图渲染；原始素材只读，派生脚本与解码缓存走现有缓存机制。

## 支持边界

这是资源与演出阅读器，不执行原游戏程序集。原作经营、进度解锁、拖拽碰撞、实时语音口型、完整互动积累状态机尚未模拟。动作和语音可独立选择，未声称自动复现原作每一阶段的随机反馈。部分剧情选择支、场景自动跳转和闪光演出仍以源脚本/记录号诊断显示。立绘情绪采用原生 Tween 的目标值，未复制整段原生 Tween 调度。

原始音频表有166个已初始化别名，其中165条不同路径；两条原生路径未出现在 ResourceManager，保留诊断，不用相似文件顶替：`Voice/cowgirl_insert`、`Voice/aegi_l_loop1`。其余163条不同的可用路径均经过真实音频解码验证。模型互动面板还可访问原始 ResourceManager 中实际存在的其他语音。

原始 DLC 翻译表还含两个只有姓名、没有正文的编号 `dlc-datashi2`、`lc-cocoa`，记录在 context.notes，不生成空场景卡片。`DLCBathroomH1` 背景别名指向当前目录中缺少的 `DLC/Images/Background/dlc_bathroom_h1`，同样保留诊断。
